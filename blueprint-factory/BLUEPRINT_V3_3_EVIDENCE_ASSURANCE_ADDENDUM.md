# Gorilla HIS — Blueprint Factory v3.3 Evidence Assurance Addendum

Status: Candidate Addendum to v3.2. This file is **additive** and MUST NOT override, weaken or bypass any v3.2 Relevance Gate, Question Suppression, Hospital Truth, Independent Challenge or Confirmation Value rule.

## Mandatory Ordering
`Hospital Truth → Domain Activation → Candidate Gap → Relevance Gate → Evidence Verification → Evidence Assurance → Independent Challenge → Confirmation Value Gate → Quality Gate`

Evidence Assurance occurs only after a candidate survives the v3.2 Relevance Gate.

## Evidence Assurance
Use:
- `standards-registry/AUTHORITATIVE_SOURCE_POLICY.md`
- `standards-registry/AUTHORITATIVE_SOURCE_REGISTRY.md`

For every expert-created Critical/High item and every formal standards/legal claim, record when applicable:
- Assurance Level A/B/C/D/E
- Source Owner
- Document / Source Title
- Edition / Version / Effective Date
- exact Section / Topic / Clause only when verified
- Official Source Locator
- Verified Date
- Applicability
- Claim Type
- Verification Status

## Formal Claim Gate
Formal external wording (`requires`, `shall`, `mandatory`, `must comply`, exact clause) requires verified Level-B authoritative evidence, exact support and applicability. Otherwise downgrade wording to `AUTHORITATIVE GUIDANCE`, `BEST PRACTICE`, or `RECOMMENDATION — STANDARD VERIFICATION REQUIRED`.

## Relevance Preservation
An authoritative source cannot create scope. It cannot resurrect a candidate that failed v3.2 Relevance Gate. A standard topic alone is not a reason to ask the hospital a question.

## Independent Challenge Extension
The second-pass reviewer additionally checks:
- wrong Evidence Assurance level;
- stale/unverified edition;
- unverified clause/mandatory wording;
- source used to manufacture relevance;
- guidance/best practice mislabeled as formal requirement.

## Quality Hard Reject Extension
Hard reject when:
1. formal requirement lacks authoritative verification/applicability;
2. authoritative source is used to manufacture relevance;
3. best practice/guidance is mislabeled formal requirement;
4. stale/unverified edition or clause is presented as verified.

## Template Extension
File 2 should include an Evidence Assurance Register for surviving relevant Critical/High and formal compliance items. Until the base template is revised without loss of v1.2 content, this addendum defines the additional required fields.

## Non-Promotion
Neither a Level-B source nor expert consensus can promote an item to HOSPITAL CONFIRMED. Explicit hospital/user confirmation remains mandatory.
