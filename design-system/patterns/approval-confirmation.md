# Pattern: Approval & Confirmation

## ใช้เมื่อไหร่
ก่อนดำเนิน action ที่มีผลกระทบสำคัญ (เปลี่ยนสถานะทางคลินิก, สั่งยา, ยกเลิกนัด, รับรองผล) — ต้องให้ผู้ใช้ยืนยันอีกครั้งอย่างมีสติ ไม่ใช่กดพลาดโดยไม่ตั้งใจ

## ระดับความเข้มของการยืนยัน (เลือกให้เหมาะกับความเสี่ยง)

| ระดับ | ใช้เมื่อ | วิธีทำ |
|---|---|---|
| **ยืนยันปกติ** | Action ทั่วไปที่ย้อนกลับได้ (เช่น บันทึกร่าง) | `modal-dialog.html` ปุ่ม "ยืนยัน" ธรรมดา |
| **ยืนยันซ้ำ (double-confirm)** | Action ที่กระทบผู้ป่วยแต่ไม่ถึงชีวิต (ยกเลิกนัด, แก้ไข order) | `modal-dialog.html` + สรุปสิ่งที่จะเกิดขึ้นให้อ่านก่อนกด |
| **Hard-stop confirm** | Action ที่มีความเสี่ยงถึงชีวิต (แพ้ยา, drug interaction รุนแรง) | ต้องกดยืนยัน**พร้อมเหตุผล**หรือพิมพ์คำยืนยัน ไม่ใช่กดปุ่มเดียวผ่าน (ดู `modules/pharmacy/README.md`) |

## โครง Modal มาตรฐาน

```
┌─────────────────────────────────┐
│  [หัวข้อ: ยืนยันการทำรายการ]      │
│  [ alert-banner.html ] (ถ้าเป็น  │
│   hard-stop level)               │
│  รายละเอียดสิ่งที่จะเกิดขึ้น        │
│  [ ยกเลิก ]         [ ยืนยัน ]    │
└─────────────────────────────────┘
```

## Component ที่ใช้ประกอบ
- `modal-dialog.html` — โครง modal หลัก
- `alert-banner.html` — ใช้เฉพาะระดับ hard-stop
- `notification-toast.html` — แจ้งผลหลังยืนยันสำเร็จ (Success/Error)

## กฎการใช้งาน
- ปุ่ม "ยืนยัน" ของ action ทำลาย/เปลี่ยนสถานะสำคัญ ห้ามใช้สีเดียวกับปุ่ม primary ทั่วไปจนแยกไม่ออก
- ห้ามปิด modal โดยกด backdrop เฉย ๆ สำหรับระดับ hard-stop (ต้องกดปุ่มใดปุ่มหนึ่งชัดเจน)
- ทุกการยืนยันสำเร็จต้องมี feedback ทันที (toast หรือเปลี่ยน state ของหน้าจอ)
