# Pattern: Dashboard / Home

เพิ่มหลัง Visual Audit — พบใน OR Team Dashboard จริง แต่ใช้เป็นแม่แบบหน้า "home" ของโมดูลอื่นได้ด้วย (เช่น หน้าแรกของ Lab, Pharmacy)

## ใช้เมื่อไหร่
หน้าแรกของ module ที่ต้องให้ผู้ใช้เห็นภาพรวมงานวันนี้ก่อนดำดิ่งเข้ารายละเอียด

## โครงหน้าจอ

```
┌─────────────────────────────────────────────────────────────┐
│  [ stat-card.html × 4-5 ]  ← แถวบนสุด ภาพรวมตัวเลขสำคัญ        │
├─────────────────────────────────────────────────────────────┤
│  Worklist หลักของวันนี้ (worklist.html)                        │
│                                                                │
└─────────────────────────────────────────────────────────────┘
```

## Component ที่ใช้ประกอบ
- `stat-card.html` — ตัวเลขสรุปสถานะงานวันนี้ (ใช้ semantic color ตามความหมายจริง เช่น critical = งานค้างเร่งด่วน)
- `worklist.html` — รายการงานที่ต้องทำต่อ

## กฎการใช้งาน
- stat card แต่ละใบต้องกดแล้วพาไปที่ worklist ที่กรองตามหัวข้อนั้นได้ (ไม่ใช่ตัวเลขที่กดไม่ได้)
- ห้ามมี stat card เกิน 5 ใบในแถวเดียว (จะแน่นเกินไป) ถ้าเกินให้พิจารณาแยกเป็น 2 แถวหรือรวมหัวข้อ
- สีของแต่ละ card ต้องสื่อความหมายตรงกับข้อมูล (งานค้าง/เร่งด่วน = critical, รอดำเนินการ = warning, เสร็จแล้ว = normal, ข้อมูลทั่วไป = info) ห้ามไล่สีตามความสวยงาม
