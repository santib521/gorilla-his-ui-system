# Pattern: Form Wizard (Multi-step Form)

## ใช้เมื่อไหร่
กรอกข้อมูลที่มีหลายขั้นตอนต่อเนื่องกัน ผู้ใช้ต้องทำตามลำดับ (หรือย้อนกลับได้)
เช่น: ลงทะเบียนผู้ป่วยใหม่ (ข้อมูลส่วนตัว → ที่อยู่ → ประวัติแพ้ยา → ยืนยัน), รับยาผู้ป่วยใน (ตรวจสอบ Order → จ่ายยา → ยืนยัน)

## โครงหน้าจอ

```
┌─────────────────────────────────────────────────────────────┐
│  Page title                                                  │
│  [Step 1: ข้อมูลทั่วไป] — [Step 2: ที่อยู่] — [Step 3: ยืนยัน]   │  ← step indicator
├─────────────────────────────────────────────────────────────┤
│  [ alert-banner.html ] (ถ้ามี critical warning ในขั้นตอนนี้)    │
│                                                                │
│  เนื้อหาของ step ปัจจุบัน (form-controls.html)                  │
│                                                                │
├─────────────────────────────────────────────────────────────┤
│  [ ← ย้อนกลับ ]                              [ ถัดไป → ]        │
└─────────────────────────────────────────────────────────────┘
```

## Component ที่ใช้ประกอบ
- `form-controls.html` — ทุก field ในแต่ละ step
- `buttons.html` — ปุ่มย้อนกลับ/ถัดไป/ยืนยัน
- `alert-banner.html` — เตือนถ้าข้อมูลใน step มีความเสี่ยง (เช่น แพ้ยาที่กรอกใหม่)

## กฎการใช้งาน
- Step indicator ต้องแสดงว่าอยู่ step ไหน และ step ใดผ่านแล้ว (เช็คถูก)
- ห้ามให้กด "ถัดไป" ผ่านได้ถ้า field บังคับยังไม่กรอก (แสดง error ตาม `form-controls.html`)
- step สุดท้ายต้องมีหน้าสรุปข้อมูลทั้งหมดก่อนกดยืนยัน (ป้องกันกรอกผิดในระบบที่กระทบผู้ป่วยจริง)
- ต้อง preserve ข้อมูลที่กรอกไว้เมื่อกด "ย้อนกลับ" (mock ด้วย JS state ง่าย ๆ พอ ไม่ต้องมี backend)
