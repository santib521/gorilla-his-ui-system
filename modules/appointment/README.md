# Module: APPOINTMENT (นัดหมาย)

## บริบทธุรกิจ
จัดการนัดหมายล่วงหน้าของผู้ป่วยกับแพทย์/คลินิก ทั้งนัดใหม่ นัดติดตาม และการจัดการตารางแพทย์

## Flow หลักที่ต้องเข้าใจก่อนออกแบบ mockup
1. ค้นหาผู้ป่วย → เลือกแพทย์/คลินิกที่ต้องการนัด
2. ดูตารางว่างของแพทย์ (calendar/slot ว่าง)
3. จองคิวนัดหมาย → ยืนยันกับผู้ป่วย (แจ้งวันเวลา)
4. จัดการนัดหมาย: เลื่อนนัด, ยกเลิกนัด, แจ้งเตือนล่วงหน้า

## ผู้ใช้งานหลัก
เจ้าหน้าที่นัดหมาย, ผู้ป่วย (ถ้ามีช่องทางจองเอง), พยาบาล

## สิ่งที่ต้องระวังเป็นพิเศษ
- ต้องแสดงตารางเวลาแบบดูง่าย (ตาราง/calendar) ไม่ใช่ list ธรรมดา
- การเลื่อน/ยกเลิกนัดกระทบคิวของแพทย์ ต้องมี double-confirm (ดู `approval-confirmation.md`)

## Pattern ที่มักใช้
`search-and-table.md` (ค้นหาตารางว่าง), `approval-confirmation.md` (ยืนยันการเลื่อน/ยกเลิกนัด)
