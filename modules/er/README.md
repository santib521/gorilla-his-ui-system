# Module: ER (ห้องฉุกเฉิน)

## บริบทธุรกิจ
รับผู้ป่วยฉุกเฉิน คัดกรองความรุนแรง (Triage) และดำเนินการรักษาเร่งด่วนตามลำดับความสำคัญ ไม่ใช่ตามลำดับมาถึง

## Flow หลักที่ต้องเข้าใจก่อนออกแบบ mockup
1. ผู้ป่วยมาถึง ER → พยาบาล Triage ประเมินความรุนแรง (เช่น ESI Level 1-5)
2. จัดลำดับคิวตาม priority ไม่ใช่เวลามาถึง
3. แพทย์ตรวจตาม priority → สั่งตรวจ/ยา/ทำหัตถการเร่งด่วน
4. ตัดสินใจ: กลับบ้าน / Admit เป็นผู้ป่วยใน / ส่งต่อโรงพยาบาลอื่น

## ผู้ใช้งานหลัก
พยาบาล Triage, แพทย์ ER

## สิ่งที่ต้องระวังเป็นพิเศษ
- **Priority ต้องเด่นกว่าข้อมูลอื่นทั้งหมดในหน้าจอ** — ผู้ป่วย priority สูงต้องสังเกตเห็นได้ทันทีแม้มองผ่าน ๆ (ใช้ `worklist.html` + `status-badges.html` ระดับ critical)
- เวลาเป็นตัวแปรสำคัญ (เวลารอ, เวลาตั้งแต่มาถึง) ต้องแสดงและอัปเดตแบบเข้าใจง่าย
- Workflow ต้องเร็วที่สุด ลด click ที่ไม่จำเป็น (ux-rules.md § 1 ข้อ 5)
