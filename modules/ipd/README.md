# Module: IPD (ผู้ป่วยใน)

## บริบทธุรกิจ
ดูแลผู้ป่วยที่ Admit นอนโรงพยาบาล ตั้งแต่รับเข้าหอผู้ป่วยจนถึงจำหน่าย (discharge)

## Flow หลักที่ต้องเข้าใจก่อนออกแบบ mockup
1. รับผู้ป่วยเข้าหอผู้ป่วย (Admission) → จัดเตียง
2. พยาบาลบันทึก vitals/สังเกตอาการตามรอบเวร (มักหลายครั้งต่อวัน)
3. แพทย์ Round ตรวจเยี่ยม → สั่งการรักษา/ยา/ตรวจเพิ่มเติมต่อเนื่อง
4. เภสัชกร/พยาบาลจ่ายยาตามรอบเวลา (MAR — Medication Administration Record)
5. แพทย์พิจารณาจำหน่าย (Discharge) → สรุปเวชระเบียน

## ผู้ใช้งานหลัก
พยาบาลหอผู้ป่วย, แพทย์เจ้าของไข้, เภสัชกร

## สิ่งที่ต้องระวังเป็นพิเศษ
- ต้องเห็นภาพรวมผู้ป่วยทั้งหอ (เตียงไหนมีใคร สถานะยังไง) ได้เร็ว — ใช้ `worklist.html` เป็นฐาน
- ประวัติแพ้ยา/อาการเปลี่ยนแปลงกะทันหันต้องเด่นชัดตลอดเวลาที่ดูแลผู้ป่วยรายนั้น (ไม่ใช่แค่ตอนแรกรับ)
- ข้อมูลต้อง real-time ต่อเนื่องหลายวัน (mock data ควรมี timeline/ประวัติย้อนหลังไม่ใช่แค่ snapshot เดียว)

## Pattern ที่มักใช้
`list-detail-page.md` (รายชื่อผู้ป่วยในหอ + รายละเอียด), `order-entry.md` (สั่งยา/สั่งตรวจต่อเนื่อง)
