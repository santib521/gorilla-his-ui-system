# Module: LAB (ห้องปฏิบัติการ)

## บริบทธุรกิจ
รับ order ตรวจจากแพทย์ เก็บตัวอย่าง วิเคราะห์ผล และรายงานผลกลับไปยังแพทย์เจ้าของไข้

## Flow หลักที่ต้องเข้าใจก่อนออกแบบ mockup
1. รับ order ตรวจจากระบบ OPD/IPD
2. เก็บตัวอย่าง (specimen) → ติด barcode
3. บันทึกผลตรวจ (manual หรือเชื่อมเครื่องวิเคราะห์ — ใน mockup ใช้ mock data)
4. ระบบ flag ค่าผิดปกติอัตโนมัติ (สูง/ต่ำ/วิกฤต)
5. รายงานผลกลับไปยังแพทย์ — ค่า critical ต้องแจ้งเตือนทันที (บางกรณีต้องโทรแจ้งด้วย — ใน mockup แสดงเป็น banner)

## ผู้ใช้งานหลัก
นักเทคนิคการแพทย์, พยาบาล (ดูผลระหว่างรอ), แพทย์

## สิ่งที่ต้องระวังเป็นพิเศษ
- ค่า critical ต้องเด่นกว่าค่า high/low ธรรมดาอย่างชัดเจน (ดู `lab-result-table.html`)
- ต้องแสดงช่วงอ้างอิง (reference range) คู่กับผลเสมอ ไม่ใช่แสดงแค่ตัวเลขลอย ๆ
