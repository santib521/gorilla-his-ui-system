# Module: OPD (ผู้ป่วยนอก)

## บริบทธุรกิจ
งานเวชระเบียนและคลินิกผู้ป่วยนอก ตั้งแต่ผู้ป่วยมาถึงโรงพยาบาลจนตรวจเสร็จ

## Flow หลักที่ต้องเข้าใจก่อนออกแบบ mockup
1. ผู้ป่วยมาถึง → เจ้าหน้าที่เวชระเบียนค้นหา/ลงทะเบียนผู้ป่วย
2. เช็คอินเข้าคิวตรวจตามแผนก/แพทย์ที่นัด
3. พยาบาลเรียกคิว → ชั่งน้ำหนัก วัด vitals
4. แพทย์ตรวจ → บันทึกการวินิจฉัย สั่งยา/ตรวจเพิ่มเติม
5. ผู้ป่วยไปรับยา/ชำระเงิน (module อื่น)

## ผู้ใช้งานหลัก
เจ้าหน้าที่เวชระเบียน, พยาบาลห้องตรวจ, แพทย์

## สิ่งที่ต้องระวังเป็นพิเศษ
- ประวัติแพ้ยาต้องเด่นชัดตั้งแต่ขั้นตอนแรกที่เปิดข้อมูลผู้ป่วย (ก่อนถึงมือแพทย์)
- คิวต้องแสดงเวลารอโดยประมาณ เพื่อบริหารความคาดหวังของผู้ป่วย
