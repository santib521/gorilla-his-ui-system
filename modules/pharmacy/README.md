# Module: PHARMACY (เภสัชกรรม)

## บริบทธุรกิจ
รับ order ยาจากแพทย์ ตรวจสอบความปลอดภัย (drug interaction, ประวัติแพ้ยา) จ่ายยา และจัดการคลังยา

## Flow หลักที่ต้องเข้าใจก่อนออกแบบ mockup
1. รับ order ยาจากระบบ OPD/IPD
2. เภสัชกรตรวจสอบ order — เช็ค drug interaction และประวัติแพ้ยาอัตโนมัติ
3. จัดยาตาม order → พิมพ์ฉลากยา
4. จ่ายยาให้ผู้ป่วย พร้อมคำแนะนำการใช้ยา
5. ตัดสต็อกคลังยา

## ผู้ใช้งานหลัก
เภสัชกร, ผู้ช่วยเภสัชกร, เจ้าหน้าที่คลังยา

## สิ่งที่ต้องระวังเป็นพิเศษ
- Drug interaction / แพ้ยา ต้อง block การจ่ายยาแบบ hard-stop ใน mockup (ต้องมีปุ่ม "ยืนยันแม้มีความเสี่ยง" ที่ต้องกดยืนยันซ้ำ ไม่ใช่ปิด alert เฉย ๆ)
- คลังยาใกล้หมด/หมดอายุ ต้องมี warning แยกจาก critical (ใช้ `--color-status-warning` ไม่ใช่ critical)
