# Module: RADIOLOGY (รังสีวิทยา)

## บริบทธุรกิจ
รับ order ตรวจทางรังสี (X-ray, CT, MRI, Ultrasound) นัดหมายเวลาตรวจ ทำการตรวจ และให้รังสีแพทย์อ่านผล

## Flow หลักที่ต้องเข้าใจก่อนออกแบบ mockup
1. รับ order ตรวจจากแพทย์ (OPD/IPD/ER)
2. นัดหมายคิวตรวจ (บางประเภทต้องเตรียมตัวผู้ป่วยล่วงหน้า เช่น งดน้ำงดอาหาร)
3. เจ้าหน้าที่รังสีเทคนิคทำการตรวจ → อัปโหลดภาพเข้าระบบ (mock เป็น placeholder ภาพ)
4. รังสีแพทย์อ่านผล → เขียนรายงานผล
5. ส่งรายงานกลับไปยังแพทย์เจ้าของไข้

## ผู้ใช้งานหลัก
เจ้าหน้าที่รังสีเทคนิค, รังสีแพทย์

## สิ่งที่ต้องระวังเป็นพิเศษ
- ผลที่ยังไม่ได้อ่าน (pending read) ต้องแยกจากผลที่อ่านแล้วอย่างชัดเจนในคิวงาน
- Order บางประเภทมีความเร่งด่วน (STAT) ต้องแสดง priority เหมือน ER

## Pattern ที่มักใช้
`order-entry.md` (สั่งตรวจ), `result-review.md` (รังสีแพทย์อ่านผลก่อนรับรอง)
