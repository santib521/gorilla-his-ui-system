# Module: REGISTRATION (เวชระเบียน / ลงทะเบียนผู้ป่วย)

## บริบทธุรกิจ
จุดแรกที่ผู้ป่วยสัมผัสระบบ HIS — ลงทะเบียนผู้ป่วยใหม่ ยืนยันตัวตนผู้ป่วยเก่า และสร้าง visit ใหม่สำหรับทุกการมาโรงพยาบาล

## Flow หลักที่ต้องเข้าใจก่อนออกแบบ mockup
1. ค้นหาว่าเป็นผู้ป่วยเก่าหรือไม่ (ด้วยเลขบัตรประชาชน/HN/ชื่อ)
2. ถ้าเป็นผู้ป่วยใหม่ → กรอกข้อมูลส่วนตัว, ที่อยู่, ผู้ติดต่อฉุกเฉิน, สิทธิการรักษา
3. ถ้าเป็นผู้ป่วยเก่า → ยืนยันข้อมูลล่าสุด อัปเดตถ้าจำเป็น
4. สร้าง Visit ใหม่ → เลือกแผนก/คลินิกที่จะไปตรวจ
5. พิมพ์บัตรคิว/ส่งต่อไปยัง module OPD

## ผู้ใช้งานหลัก
เจ้าหน้าที่เวชระเบียน

## สิ่งที่ต้องระวังเป็นพิเศษ
- ต้องเช็ค**ผู้ป่วยซ้ำ**ก่อนสร้างประวัติใหม่เสมอ (ป้องกัน HN ซ้ำซ้อน)
- สิทธิการรักษา (ประกันสังคม/บัตรทอง/เบิกจ่ายตรง) กระทบ flow การเงินภายหลัง ต้องเลือกให้ถูกตั้งแต่ต้น
