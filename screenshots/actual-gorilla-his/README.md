# screenshots/actual-gorilla-his/

เก็บภาพหน้าจอ **ของจริง** จากระบบ Gorilla HIS ที่ใช้งานอยู่ในโรงพยาบาลปัจจุบัน (ไม่ใช่ mockup) — ใช้สอน AI และทีมให้รู้จัก "หน้าตาจริง" ของผลิตภัณฑ์ก่อนเริ่มออกแบบ mockup ใหม่

## กฎสำคัญ — ต้องทำก่อน commit ทุกครั้ง

**ต้องลบ/เบลอข้อมูลที่ระบุตัวตนผู้ป่วยได้ทั้งหมดก่อน** (ชื่อ-สกุลจริง, HN จริง, เลขบัตรประชาชน, วันเกิด, ที่อยู่, เบอร์โทร ฯลฯ) ก่อนนำภาพเข้า repo นี้เด็ดขาด — ไม่มีข้อยกเว้น

## สถานะปัจจุบัน

โฟลเดอร์นี้ยังว่าง (ยังไม่มีภาพจริงพร้อมใช้) — ระหว่างนี้ทีมใช้ `design-system/design-rules.md` § 0 (Product Character) เป็น baseline ชั่วคราวไปก่อน

## เมื่อมีภาพพร้อมแล้ว

1. เบลอ/ครอปข้อมูลผู้ป่วยตามกฎด้านบน
2. ตั้งชื่อไฟล์: `<module>-<หน้าจอ>-<YYYYMMDD>.png` เช่น `opd-patient-search-20260915.png`
3. จัดประชุม **Visual Audit** กับทีม — เทียบภาพจริงกับ `design-system/tokens.css` และ `design-rules.md` ปัจจุบัน แล้วอัปเดตให้ตรงกับของจริง (สี, ฟอนต์, spacing, การจัดวาง)
4. อัปเดต `design-rules.md` § 0 Product Character ให้สะท้อนของจริง แทนค่า baseline เริ่มต้น
